Sidebar mockup — nested groups

Two-level structure. Top-level categories (uppercase) collapse the whole thing; sub-groups (mixed case) collapse just that section. Both states persist in localStorage. Click any header to try it out.

What changed

Rename Setup → Manage — Setup sounded one-time; Manage conveys ongoing record-keeping.

Money In → 3 sub-groups

Billing · Receiving · Collections.

Manage → 2 sub-groups

People (Homeowners, Properties, Renters, Vendors) · Accounts & Banking (Bank Accounts, Account Setup, Budget, Bill Templates). Bill Templates lives with the other configuration items.

New: Getting Started

Top of the sidebar (right after Home) for onboarding-but-not-one-time tasks: Account Setup Wizard and Starting Balances. Visible reminder that there's setup work still to do.

💡 Pairs with the existing dashboard Alerts — a persistent "You haven't entered Starting Balances yet" nudge with a Stop nagging me acknowledge button (saved to DB, not session). Saved as a future task.

New: Corrections

One-item category for Manual Adjustments (journal entries) — the "fix what I F#%ked up" bucket. Keeps accounting-heavy tools out of the friendlier Month-End flow. Room to grow: future void/reverse tools would land here too.

Admin → 4 sub-groups

Configuration · Data I/O · Customization (was Content — Wizard Catalog + Workflow Editor) · System.

Removed: Look It Up

Transaction History and Account Detail move into Reports as two more report types. They're accounting-heavy and most users won't touch them — better one click deeper inside Reports than their own sidebar category.

Small, flat groups stay flat

Getting Started, Money Out, Month-End, Reserve Fund, Corrections, and Guides don't need a second level — their items already belong together.

Default state

Top-level groups default to expanded; sub-groups default to collapsed so the sidebar starts quiet. User expand/collapse is remembered per-browser.
