💡 What is Claude Code?

Claude Code is a tool made by Anthropic ↗ that lets you have a conversation with an AI that can actually read, write, and change the code for your application — like texting a knowledgeable developer friend who never sleeps, never gets impatient, and already knows your entire codebase.

You describe what you want in plain English. Claude Code reads the existing code, figures out what needs to change, makes the edits, and explains what it did. You don't need to understand the code — you just need to describe the outcome you want.

Already have Claude for Mac? Great news — Claude Code is already inside it. Look at the top of the Claude for Mac window. You'll see three icons: Chat (conversation), Routines, and </> Code. That Code button is Claude Code. Click it and you're ready — no installs, no terminal, nothing extra needed. This entire HOA app was built using exactly that button.

💬 Ready-to-Use Prompts — Copy & Paste These

Not sure what to say? Start with one of these. Click the copy button, paste it into Claude Code, and edit the parts in [brackets] to match what you actually want.

Add a new feature 
I'd like to add a new feature to the HOA accounting app. Here's what I need:

[Describe what you want in plain English. Example: "I want a page where I can track parking violations — record the date, lot number, description of the violation, and whether a fine was issued."]

Please show me what you plan to build before making any changes, and explain how it will fit into the existing app.
Fix something that's broken 
Something isn't working correctly in the app and I need help fixing it.

Here's what's happening: [Describe the problem. Example: "When I try to save a new vendor, I get an error message that says 'Internal Server Error' and the vendor doesn't get saved."]

Here's what I expected to happen: [Example: "The vendor should be saved and I should see it in the vendor list."]

Steps to reproduce: [List the exact steps you took before the problem appeared.]

Can you find and fix the issue?
Change how something looks 
I'd like to change the appearance of something in the app.

What I want to change: [Example: "On the Owners list page, the table feels cramped. I'd like more breathing room between rows, and I'd like the owner's name to be bold."]

Please make the change and show me a screenshot so I can confirm it looks right before we finalize.
Add a new report 
I need a new report added to the Reports section of the app.

Report name: [Example: "Annual Dues Collection Summary"]

What it should show: [Example: "For a selected year, show each lot, the total dues charged, total payments received, and the outstanding balance. Group by quarter and show totals at the bottom."]

Format: [Example: "A table I can print or export to PDF."]

Please add this report to the Reports page and include it in the navigation.
Change a label, message, or default value 
I'd like to change some text or a default value in the app.

What to change: [Example: "On the Bill Assessments page, the button currently says 'Post Assessments'. I'd like it to say 'Charge Dues' instead because that's clearer for our board members."]

[Or: "The default late fee amount is $25. We've changed our policy and it should default to $35."]

Please find everywhere this text or value appears and update it consistently.
Understand how something works 
I have a question about how the app works internally. I'm not a developer but I want to understand this so I can make a good decision about changing it.

My question: [Example: "When I post a payment from an owner, what exactly happens in the system? Does it record a transaction? Does it update the owner's balance automatically?"]

Please explain it in plain English without assuming I know accounting software terminology.
Add a new field to an existing page 
I'd like to add a new field to an existing page in the app.

Page: [Example: "The Owners / Homeowners edit page"]

New field: [Example: "An optional 'Board Role' field — a dropdown with options: None, President, Vice President, Treasurer, Secretary, Board Member at Large."]

Where to store it: [Example: "Save it with the owner record so it shows in the owners list."]

Please add the field to the form, save it to the database, and display it in the owners list.
Ask for help deciding what to build next 
I'm trying to decide what to improve next in this HOA accounting app. Here's some context about our association:

[Example: "We have 47 homes, collect annual dues of $850, and our biggest pain points are tracking who is late on payments and communicating with owners about their balances."]

Based on what already exists in this app, what features or improvements would have the most impact for an HOA like ours? Give me 3-5 ideas with a brief explanation of what each would involve.
✨ Tips for Getting Great Results
  • 🎯 Be specific about what you want, not how to build it. Say "I need to track parking violations" not "create a database table with these columns." Claude figures out the technical details — you describe the outcome.
  • 📸 You can share screenshots. If something looks wrong or you want to show Claude what you're seeing, paste a screenshot right into the Claude Code chat. It can see images.
  • 🔁 It's a conversation — go back and forth. If the first result isn't quite right, just say what you'd like changed. "That's close, but can you make the table sortable?" You don't start over.
  • ✅ Claude will ask before changing anything significant. You'll see a summary of what it plans to do. If something looks wrong, just say "no" or "let's try a different approach." Nothing is irreversible without your approval.
  • 💾 Use git to save your work. Claude Code works with git — a system that saves snapshots of your code. Ask Claude Code: "Create a git commit to save these changes." This means you can always go back if something goes wrong.
  • 🤝 You don't need to be a developer. The person who built this entire app isn't a software developer — he's an HOA treasurer who described what he needed in plain English. If he can do it, you can too.
