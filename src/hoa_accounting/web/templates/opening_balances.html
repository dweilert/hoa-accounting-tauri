How to set up Starting Balances
1
What this screen does.
Think of it as telling the system "here's how much money we have right now." You enter the current balance of each bank account so the system knows where things stand from day one.
2
Where to get the numbers.
Grab your most recent bank statement for each account and enter the ending balance shown. If you're starting mid-year, use the balance from the day before you began using this system.
3
What happens when you save.
The system records those balances and uses them as the starting point for all future reports and statements. Nothing complicated — it's just telling the system where you're starting from.
4
Homeowner balances (optional).
If any homeowners had unpaid dues or assessments before you started using this system, you can enter what each one owes here. This keeps the "Who Owes Money" and past-due reports accurate from day one. If everyone is starting fresh with a zero balance, you can skip this section.
5
Made a mistake? No problem.
Just come back to this screen, fix the number, and save again. The system will update to reflect your correction — nothing is permanent until you're happy with it.
