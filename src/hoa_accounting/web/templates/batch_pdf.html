Generates a PDF Owner Ledger for every active lot and uploads them to mmpoa-owner-reports on AWS S3. Each file is stored at owner-reports/{lot}/{year}/{filename} and returns a pre-signed URL (1-hour expiry).

This may take a minute depending on the number of lots.
