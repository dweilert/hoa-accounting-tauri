{# ── Maintenance ─────────────────────────────────────────────────── #}
Maintenance
Routine operations to keep the database fast and compact. Each runs immediately — no data is changed or deleted.
{# Rebuild Indexes #}
Rebuild Indexes
Drops and recreates every index. Useful after bulk deletes or if the health check reports index corruption.
{# Compact (VACUUM) #}
Compact Database
Rebuilds the database file from scratch, reclaiming space from deleted rows. Run after large batch deletes. Shows size before and after.
{# WAL Checkpoint #}
WAL Checkpoint
Flushes the write-ahead log back into the main database file. Only applicable when journal mode is WAL — current mode: {{ stats.journal_mode | upper }}.

Backup & Restore
Download a point-in-time backup of the live database, or restore from a previously saved backup file. The backup uses SQLite's built-in snapshot mechanism, so it is always consistent even while the app is running.
{# Backup and Download #}
